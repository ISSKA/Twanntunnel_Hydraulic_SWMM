# Format recommande pour les lignes d'actions:
#   set_diameter link=<conduit> diameter=<diametre_m>
#   set_roughness link=<conduit> roughness=<n_manning>
#   set_length link=<conduit> length=<longueur_m>
#   add_junction name=<node> elevation=<radier_m> max_depth=<m> x=<coord_x> y=<coord_y>
#   add_conduit name=<conduit> from=<node_amont> to=<node_aval> length=<m> roughness=<n> diameter=<m>
#
# Les variantes sont cumulatives entre phases. Avec combine_variants_within_phase yes,
# elles sont aussi combinees a l'interieur d'une meme phase:
#   phase 1: 3 variantes
#   si une variante est sans action, elle reste seule et n'est pas combinee
#   avec les variantes actives pour eviter les doublons V0+V1 = V1.
#   phase 1 avec V0 + 3 variantes actives: 1 + (2^3 - 1) = 8 combinaisons
#   phase 2 avec V0 + 3 variantes actives: 8 x 8 combinaisons
#   phase 3 avec V0 + 3 variantes actives: 8 x 8 x 8 combinaisons
#   ...
#   phase 8: 8^8 combinaisons, avant multiplication par les hydrologies declarees.
#
# Les actions placees directement sous une phase sont communes a toutes les
# variantes de cette phase. Les actions sous "variant" ne s'appliquent qu'a la
# branche correspondante, mais elles sont reprises par toutes les phases suivantes.
